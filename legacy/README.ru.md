## Как настроить такую же читалку

1. На читалке: Settings → Connectivity → Wi-Fi → добавить сеть `<your Wi-Fi network>` с паролем. Пароли с читалки не выгружаются.
2. На читалке: Home → File Transfer → Join a Network, запомнить IP с экрана.
3. На Маке: `cd ~/Xteink && node restore.mjs <IP> --dry-run`, посмотреть, что изменится.
4. Потом то же без `--dry-run`.

Что делает `restore.mjs`:
- удаляет шрифты, которых нет в `fonts/`, и загружает недостающие;
- кладёт `РУКОВОДСТВО.epub` в корень;
- выставляет настройки из `settings.json`. Варианты сопоставляются по названию, а не по номеру, потому что номер шрифта зависит от установленных шрифтов.

`--settings-only` пропускает шрифты и руководство.

## Что в папке

- `fonts/`: векторные TTF, собранные под читалку (обычный, жирный, курсив, жирный курсив), лицензия OFL, всего 2 МБ:
  - Literata 3.103, статика из релиза googlefonts/literata;
  - Noto Sans, Merriweather, Roboto: статика из вариативных шрифтов google/fonts (wdth 100, у Merriweather opsz 18).
  - Во всех четырёх одинаковый набор: латиница с расширениями (французский, латынь с долготами), кириллица,
    греческий с политоникой, пунктуация, стрелки. Кернинг сохранён.
  - Недостающее взято из доноров и подогнано по высоте строчных: греческий для Literata и Merriweather из Noto Serif,
    для Roboto из Noto Sans; стрелки для Noto Sans и Roboto из Noto Sans Math.
  - Сборка: `tools/build_fonts.py` (fontTools: instancer, subset, merge), команда в шапке файла.
  - Запасного шрифта у прошивки нет: символ, которого нет в шрифте, на экране просто пустой.
  - Встроенный в прошивку Noto Sans остаётся сам.
- `settings.json`: полный снимок `GET /api/settings`.
- `РУКОВОДСТВО.epub`: шпаргалка, лежит в корне читалки.
- `fonts_compare.html`: сравнение шрифтов для чтения.

## Особенности

- Урезанные CPFONT из комплекта показывают «?» вместо редких символов, например «→». Поэтому стоят полные TTF.
- Проверка покрытия: обе книги Шопенгауэра (с греческими эпиграфами) — 0 недостающих символов во всех 16 файлах.
- После удаления выбранного шрифта читалка переключается на встроенный Noto Sans, шрифт надо выбрать заново.
- Загрузка шрифтов через веб: `http://IP/fonts`, лежат в `/.fonts/<Семейство>/`.

### Порядок

1. Копия с читалки: `node tools/backup_reader.mjs <IP> <папка>` — книги и `/.crosspoint` (прогресс).
2. Распаковать: `unzip -q книга.epub -d dir`.
3. Исправить:
   - `node tools/bracket_footnotes.mjs dir` — сноски по правилу;
   - `node tools/epub_repair.mjs dir` — огрехи конвертации FB2 → EPUB без изменения вида: alt у картинок, битые якоря
     оглавления, пустой guide, `<span>`/`<p>` вокруг блоков → `<div>`, текст прямо в `<blockquote>` → в `<div>`.
     Перед этим убедиться, что в CSS нет правил на голые `div`/`span`/`p`.
4. Упаковать: `cd dir && zip -X0 ../out.epub mimetype && zip -X9 -r ../out.epub . -x mimetype -x ".*"`.
5. Линтеры, все должны быть чистыми:
   - `node tools/bracket_audit.mjs dir` — «без [ ]: 0; прилипло или пробел перед знаком: 0»;
   - `node tools/text_same.mjs исходный_dir dir` — текст совпадает по буквам (пробелы и скобки не в счёт);
   - `xmllint --noout` по каждому XHTML;
   - `epubcheck out.epub` (`brew install epubcheck`, нужна Java) — 0 ошибок;
   - `node tools/epub_lint.mjs --ref <папка оригиналов> out.epub` — mimetype, манифест, все ссылки и якоря, число ссылок как в оригинале.
6. Заменить на читалке с возвратом прогресса:
   `node tools/replace_books.mjs <IP> <папка с epub> <папка копии> '{"Мир как воля":"epub_3035184416"}'`.
   Папка прогресса книги — по `book.bin` в копии. Скрипт стирает старый кэш страниц и кладёт только `progress.bin`.

   187 страниц) та же страница приходится на чуть более ранний текст. Пролистать вперёд пару страниц.

## Заставки сна

- Инструмент: `python3 -I tools/sleep_image.py <кадр> <выход> [x0] [--fix-color]` — обрезка под 5:3, мягкий серый
  (уровни + чуть светлее середина, без резкости и дизеринга — остальное делает прошивка) →
  BMP 24 бит в родной ориентации (800×480; прошивка krinik рисует свою заставку в ориентации чтения). `--portrait-file` —
  старая раскладка 480×800 с поворотом, для стоковой прошивки. `x0` — куда сдвинуть рамку: 0 левый край, 1 правый, 0.5 центр. `--fix-color` — для мутного кадра.
- На карте: `/.sleep/*.bmp` — случайная при каждом сне; `/sleep.bmp` — одна, главнее папки. Экран сна → Свой.
- `.sleep` через Wi-Fi не создать: веб-сервер запрещает имена с точкой (403). Делать по кабелю (режим USB Drive) или
  `node tools/sleep_upload.mjs <IP> <папка>` — он кладёт в запасную `sleep`.
- Сделано 03.11.2026: 6 кадров Oblivion в `sleep/ready/`; сейчас `sleep.bmp` = пятая (руины у пристани).

### Экран X4 Pro: замер и поправка (03.11.2026) — главное

Экран сна показывает тона совсем не так, как файл. Замер по фото шкалы `tools/panel_scale.py`
(файл → видно на экране, 0 = чёрный, 100 = белый):

| Файл | 0–10 % | 10→15 % | 15–30 % | 30→35 % | 35–55 % | 60–80 % | 85–100 % |
|---|---|---|---|---|---|---|---|
| Экран | 0–11 % | скачок до 39 % | 39–67 % | скачок до 80 % | **плато ≈ 80 %** | 86–100 % | белое |

Бендинг на градиенте Николай видит в 10–15, 32–34 и слегка 50–65 %. Поэтому всё «белёсое», лес на плато
сливается в один тон, а небо с солнцем — в белое.

**Рецепт, который отлично выглядит на читалке** (кадр 5):
`python3 -I tools/sleep_image.py <кадр> <выход> 1.0 --fix-color --recipe5 --panel`
— цветокор без обрезки белого, дымка 0.8, гамма 1.3, сжатие только неба (от 78 %), тени +0.5,
и последним шагом `--panel`: обратная таблица экрана (`PANEL_RESPONSE` в `sleep_image.py`), плато 35–55 % не используется.
Готовишь картинку такой, какой она должна выглядеть на Mac, — `--panel` переводит её в язык этого экрана.
На Mac файл выглядит очень тёмным — так и надо.

Не сработало (не повторять): сильный локальный контраст + резкость («страшно»), свой дизеринг Floyd–Steinberg / Atkinson /
Bayer, постеризация в 4 ступени. Другая читалка или прошивка — снять шкалу заново и обновить `PANEL_RESPONSE`.

### Запись на карту по кабелю (режим USB Drive) — после каждой записи чистить

macOS при каждой записи на FAT создаёт рядом скрытый двойник `._имя` (cp -X не спасает). Библиотека читалки показывает
`._книга.epub` как лишнюю книгу (так появилось второе «РУКОВОДСТВО»), а `._*.bmp` в `.sleep` прошивка может взять
заставкой и показать тёмный экран. После записи: `sh tools/card_clean.sh "/Volumes/NO NAME"` — удаляет только настоящие
AppleDouble (метку пересканирования библиотеки не ставить: от неё зависало главное меню). По Wi-Fi двойники не появляются.
Книгу, которую читалка уже открывала, заменять вместе с удалением её кэша `/.crosspoint/epub_<хеш>/` (иначе покажет старую).
- Картинки, которые кладу в книги, — не больше экрана (≤ 790×470 для альбомного чтения): картинка 1840 px шириной заставила читалку «зависнуть» на конвертации (03.11.2026). Зависла — подождать минуту; не ожила — Reset, затем держать Power.

### Картинки внутри книг (замер 03.11.2026, `КАЛИБРОВКА.epub`)

Внутри EPUB прошивка рисует картинки сама, своим дизерингом (узоры в светлых тонах), и кривая другая, чем у экрана сна:
тени ≤ 15 % уходят в чёрное, середина почти честная (50 → 50 %), ≥ 95 % — белое. Таблица `BOOK_RESPONSE`
в `sleep_image.py`, поправка `--book` (или `--book=0.5`). Проверка на экране (Николай):
- пейзажи и наши заставки в книге — поправка целиком (`--recipe5 --no-lift --book`: свой подъём теней рецепта не нужен, его делает поправка);
- портреты и иллюстрации, подготовленные издателем для печати, — **не трогать** (поправка их высветляет).
Тени 0–15 % камера сняла неточно; если понадобится точнее — шкала 0–20 % с шагом 2 %.
- Правила для картинок в книгах (Николай, 03.11.2026): подготовленные к печати — не трогать; не подготовленные портреты — ½,
  сцены/пейзажи — целиком (после уровней: бумага скана → белая); графики, таблицы, чертежи — жёсткий ч/б, чтобы были видны.
  Инструмент: `python3 -I tools/book_images.py <распакованная книга> '{"файл": "bw|half|full|keep"}'`.
  Сделано 03.11.2026: «Корень» — 6 чертежей ч/б, Докинз — 8 графиков ч/б, Шекспир — портрет ½ и 10 сцен целиком;
  «Мир как воля» не тронут (всё подготовлено к печати). Линтеры чистые, прогресс «Корня» сохранён.
- Дубли в «Библиотеке» после записи по кабелю — это призраки `._*` в индексе `/.crosspoint/library.idx`. Чистка двойников
  их не убирает: удалить `library.idx` (кэш, книги и прогресс не трогает), перезагрузить, дать 1–2 минуты на пересборку.
  Проверено 03.11.2026: стало ровно 6 книг.

  в кэш `/.crosspoint/view_*.bmp` (пока на чистом листе «Загрузка»), повторный показ — сразу из кэша. Маленькие
  картинки растягиваются на экран; в тёмной теме картинка позитивная, поля чёрные. Картинки готовить как заставки:
  BMP 24 бит в родной ориентации (альбомные 800×480) — 1:1 в ориентации чтения, тем же путём, что заставки
  (кривая + Atkinson); поворот долгим тапом — на редкий случай. JPG/PNG — дизеринг Bayer.

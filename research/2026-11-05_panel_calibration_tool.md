# Калибровка экрана по фото — веб-инструмент (план, 05.11.2026)

Слово Николая (11:31): «Веб-инструмент, HTML-страница, в которую пользователь загружает фотографию читалки — инструмент сам
кропает, вращает нужным образом, анализирует и выполняет расчёт кривой, даёт юзеру файл и руководство, куда его залить на
читалку. ОЧЕНЬ добрый к юзеру инструмент, который поясняет, как откалибровать читалку».

## Что уже есть

- Прошивка krinik читает кривую `/.crosspoint/panel_curve.txt`: 256 целых 0..255, «желаемый тон → значение для 4-серого
  дизеринга» (`src/util/PanelCurve.{h,cpp}`). Нет файла или битый файл → встроенная кривая этой X4 Pro (замер 03.11).
  Файл 0,1,…,255 выключает поправку. Читается раз после загрузки; пробуждение из сна — это загрузка.
- Кривая работает во вьювере картинок и на своих заставках сна; книги рисует другой путь (своя кривая, `--book`), он вне
  задачи.
- Ручной метод: `tools/panel_scale.py` (карточка ступеней), фото, глазами — какие ступени сливаются.

## Поток пользователя

1. Страница: «Скачать калибровочную карточку» → `panel_calibration.bmp` (480×800, генерирует сама страница).
2. Положить в корень карты (кабель или «Передача файлов» по Wi-Fi), открыть на читалке в «Обзоре файлов».
3. Сфотографировать экран телефоном: ровно, без блика, карточка целиком. Можно открыть страницу прямо на телефоне —
   кнопка «Сфотографировать».
4. Страница сама находит четыре метки, выпрямляет перспективу, определяет поворот, меряет 33 ступени, выравнивает
   освещение по белому полю и чёрным меткам, строит кривую. Показывает, что нашла, график и «было/станет».
5. «Скачать panel_curve.txt» → положить в корень карты → усыпить и разбудить читалку.
6. По желанию — проверочное фото: та же карточка уже с кривой; страница показывает, насколько ровно.

Каждый шаг — с картинкой-подсказкой и понятным языком; ошибки — что случилось и как переснять (блик, далеко, темно,
метки не найдены → ручной режим: ткнуть в четыре метки).

## Условия съёмки (Николай, 11:36 — так снималась замеренная кривая; 11:36 «это нужно наглядно нарисовать»)

Подсветка читалки ВЫКЛ; светлая тема (не «Ночной режим»); хорошее освещение экрана, лучше на улице при естественном
солнечном свете; без бликов; без наклона экрана относительно камеры. На странице — рисунки «так / не так» (SVG).
Ночной режим страница распознаёт по обратному порядку ступеней и просит выключить.

## Страница

Один HTML-файл без сервера, без внешних библиотек (своё: адаптивный порог, компоненты, метки с «дыркой», гомография,
выборка, изотоническая регрессия, обратная таблица). Русский/английский переключателем (по языку браузера). Место в форке:
`tools/panel-calibration/index.html` (для PR и GitHub Pages — по слову Николая).

## Риски

- Камера телефона не линейна и сама подстраивает экспозицию: нормировка по чёрным меткам и белому полю локально
  (плоскость по точкам), тени 0–15 % камера снимает неточно — предупреждать, проверочное фото.
- Блик e-ink под лампой — проверка разброса белого.
- HEIC с iPhone в Chrome не читается — подсказка «Наиболее совместимый» / скриншот / снять через страницу.

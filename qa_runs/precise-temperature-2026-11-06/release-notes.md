# debug3 — «Точная температура»

Настройки → Экран → «Точная температура»: включает точное смешивание тёплого и холодного света на яркостях до10% включительно. Для старых настроек опция включена.

Выше10% постоянный программный дизеринг отключён при любом положении галочки. При плавном переходе дробное смешивание допускается только в нижней части диапазона; временный таймер анимации работает до её окончания. При выключенной галочке остаётся целочисленное смешивание: на самом слабом свете оттенок может измениться.

Батарейный лог сохранён с интервалом1минута. Новая прошивка не управляет зарядником и не вводит ограничитель тока светодиодов. Экономия АКБ ещё не измерена.

Проверка на устройстве: hardware-check.md рядом с этим файлом.

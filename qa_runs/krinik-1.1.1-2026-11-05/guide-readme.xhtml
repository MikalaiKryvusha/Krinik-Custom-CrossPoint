РУКОВОДСТВО

Читалка

Модель: Xteink X4 Pro (подсветка, сенсор)

Прошивка: cp-2.0.0-krinik-1.1.1 (своя сборка CrossPoint)

Память: microSD 16 ГБ, FAT32, диск X4-KRINIK

Файловые системы: FAT16, FAT32, exFAT; NTFS и APFS — нет

Карта больше: до 32 ГБ — FAT32; от 64 ГБ — exFAT; у владельцев работают 256 и 512 ГБ

Форматировать: на Mac — Дисковая утилита, MS-DOS (FAT) или ExFAT, схема MBR

Форматы

Книги: EPUB (лучший), TXT, XTC/XTCH

Картинки: BMP; заставки — BMP, PNG

Шрифты: TTF, OTF (все кегли 8–22 pt), CPFONT (кегли 12–18)

Нет: FB2, PDF, MOBI → сначала в EPUB (Calibre)

Файлы на карте

/Книги: книги

/.fonts: шрифты; загрузка — http://IP/fonts

/sleep: заставки сна (видна в проводнике)

Порядок заставок: Настройки → Экран → Порядок обложек сна: случайный или по порядку

/sleep.bmp: запасная, если папка пуста

Заставка: BMP 24 бит, 480×800 (портрет), ровная, как для Mac; Экран сна → Свой; Фильтр экрана сна → Нет

Кривая экрана: /.crosspoint/panel_curve.txt — читалка сама подгоняет тона заставок под экран

/screenshots: скриншоты

/.crosspoint: кэш и настройки — не трогать

Шторка и управление

Шторка: свайп вниз от верхнего края экрана

Луна: ночной режим (белое на чёрном)

Круговые стрелки: перерисовать экран, убрать следы

Чистый домашний экран: Настройки → Экран → Настройки очисток экрана → Очищать домашний экран

Буква T: поворот текста; значок поворачивается

Рука: касания в книге вкл/выкл; выкл — листать кнопками

Значок залит: вкл; контур: выкл

Солнце: подсветка вкл/выкл, плавно (Настройки → Экран → Плавная подсветка)

Ползунки: яркость и теплота

Меню книги: тап по экрану

Фонарик: на главном экране; белый экран, подсветка плавно до 100 %; выйти — «← Выйти» вверху, тап в любом месте, Назад или Домой; подсветка плавно вернётся, как была (или погаснет, если была выключена)

PWR коротко: сон; PWR 2 раза: подсветка

Home 2 раза: подсветка; Home долго: меню

Шрифт: Literata (полная TTF) 16 pt, +10%; встроенный — Noto Sans

Wi-Fi: своя сеть

Путь: Home → File Transfer → Join a Network

Адрес: на экране (QR, IP), сейчас http://192.168.1.7

Или: http://crosspoint.local

В браузере: Files → Upload, папки, удаление, перенос

Сети Wi-Fi: Settings → Connectivity → Wi-Fi или http://IP/settings

Wi-Fi: без роутера

Путь: File Transfer → Create Hotspot

Сеть: CrossPoint-Reader (открытая)

Адрес: http://192.168.4.1

Calibre по Wi-Fi

Плагин: CrossPoint Reader → Host = IP читалки

Читалка: File Transfer → Calibre Wireless

Calibre: Send to Device → Send to main memory

Ещё: WebDAV на том же адресе; приложение CrossPoint Sync

Провод с ПК

USB-C: режим USB Drive — карта видна диском

Нет режима: вынуть microSD → картридер ПК

Конец: извлечь диск безопасно, потом кабель

Совет: после передачи выйти из File Transfer — Wi-Fi жрёт батарею

Обращение с читалкой

Вода: не защищена; брызги — сразу вытереть, в воду не ронять

Намокла: выключить, не заряжать, сушить сутки при комнатной температуре

Солнце: читать можно; не оставлять на солнце и в машине — нагрев выше 50 °C

Экран: сухая микрофибра; пятно — чуть влажная водой; без спирта, стеклоочистителя, давления

Работа: 0…50 °C; хранение: −25…60 °C (паспорт экрана)

Холод: ниже нуля экран медленный, тянет следы; с мороза — дать согреться в сумке, потом включать

Жара: выше 50 °C экран может испортиться, батарея — разбухнуть

Зарядка: при 0…45 °C; на холоде нельзя — батарея теряет ёмкость навсегда

Батарея: 1100 мА·ч; держать 20–80 %, в ноль не сажать

Блок питания: обычный 5 В от телефона; заряжать не под подушкой

Надолго в ящик: зарядить до половины, подзаряжать раз в 3 месяца

Язык: язык интерфейса; 32 языка

› Часовой пояс: выбор пояса из списка

› Летнее время: Авто — по правилам пояса; ВКЛ — всегда +1 ч; ВЫКЛ — без сдвига

› Показывать в заголовке: ВКЛ — время в шапке экранов меню; ВЫКЛ — нет

› Синхр. часов: поставить время по интернету (NTP); нужен Wi-Fi

Раскладки клавиатуры: какие языки есть в экранной клавиатуре; флажок на каждый язык

Проверить обновление: по Wi-Fi ищет официальную CrossPoint на GitHub; установка заменит свою сборку krinik

Прошивка с SD карты: выбрать файл .bin на карте и прошить его

Показать скрытые файлы: ВКЛ — файлы и папки с точкой (.sleep, .fonts, .crosspoint) видны в проводнике и в веб-файлах; ВЫКЛ — скрыты

Об устройстве: модель, прошивка, процессор, объём SoC Flash, файловая система SD, объём, занято и свободно на SD, контроллер экрана, разрешение, тачскрин, подсветка, часы, датчик наклона, MAC-адрес

Настройки: Экран

Экран сна: что на экране во сне; Тёмный — логотип на чёрном; Светлый — логотип на белом; Свой — картинка из /sleep и /.sleep, нет картинок — /sleep.bmp, нет и её — Тёмный; Обложка — обложка открытой книги, нет книги — Тёмный; Обложка + Свой — обложка, если уснула из книги, иначе Свой; Нет — пустой экран; Быстрое возобновление — остаётся страница книги со значком луны, пробуждение сразу в книгу; Прозрачный — картинка из /.sleep-overlay или /sleep-overlay поверх текущего экрана, белое прозрачно; Cover + Transparent — та же картинка поверх обложки последней книги

Сон через: бездействие до автосна; 1–30 мин; Никогда — сам не засыпает

Режим обложки сна: как ложится обложка или своя картинка; Вписать — целиком, по краям белые поля; Обрезать — на весь экран, лишнее срезается

Порядок обложек сна: Случайный — любая картинка из /sleep и /.sleep, одна и та же два раза подряд не выпадает; По порядку — следующая по имени файла, после последней снова первая; Одна картинка — только /sleep.bmp, папки не читаются. В папках нет картинок или нет /sleep.bmp — стандартная заставка. «На экран сна» во вьювере записывает картинку в /sleep.bmp и сам ставит «Одна картинка»; вернуть смену заставок — выбрать здесь Случайный или По порядку

Ориентация заставки сна: для своих картинок, от ориентации чтения не зависит; По картинке (по умолчанию) — вертикальная картинка книжно, горизонтальная — альбомно, читалка повёрнута против часовой (родная ориентация экрана 800×480, как «Альбомная 180°»); Книжная, Альбомная, Книжная 180°, Альбомная 180° — всегда так, какой бы ни была картинка. Картинки лежат «верхом вверх»: 480×800 для книжной и 800×480 для альбомной ложатся на экран 1:1, без пересчёта

Подсветка на засыпании: ВЫКЛ / 2 сек / 5 сек / 10 сек — сколько подсветка ещё горит над только что нарисованной заставкой, прежде чем читалка уснёт; в конце плавно гаснет за время из «Плавной подсветки»; нажатие кнопки питания в это время отменяет сон — свет не гаснет, читалка возвращается в книгу или на главный; работает, только если подсветка была включена

Плавная подсветка: ВЫКЛ / 200 мс / 500 мс / 1000 мс — за сколько подсветка плавно загорается и гаснет: Солнце в шторке, двойное нажатие, пробуждение, «Фонарик», конец «Подсветки на засыпании»; ВЫКЛ — сразу

Фильтр экрана сна: для своей картинки и обложки; Нет — 4 оттенка серого, тона подгоняются кривой экрана (встроенная, /.crosspoint/panel_curve.txt её заменяет); Контраст — только чёрное и белое; Инверсия — чёрное и белое наоборот; при Контраст и Инверсия кривая и серые не действуют

Возобновление по таймауту: ВКЛ — при автосне по «Сон через» остаётся страница книги, пробуждение сразу в книгу; сон кнопкой — обычный «Экран сна»; ВЫКЛ — всегда «Экран сна»; включается само при Быстром возобновлении

Скрыть % батареи: Никогда — процент везде; В режиме чтения — в книге без процента; Всегда — процента нет нигде; значок батареи остаётся

Тема интерфейса: вид меню, меняется сразу; Классическая — исходный вид; Lyra — скругления и значки; Lyra Extended — Lyra, на главном 3 книги вместо 1; RoundedRaff — скруглённая, с доп. оформлением; Сетка обложек — главный экран сеткой обложек библиотеки

Подсветка при пробуждении: ВКЛ — горела перед сном, загорится после, плавно (см. «Плавная подсветка»); ВЫКЛ — просыпается без подсветки

Ночной режим: ВКЛ — весь экран белым по чёрному (как Луна в шторке); ВЫКЛ — чёрным по белому

Настройки очисток экрана: последний пункт «Экрана», отдельный экран со всеми очистками и перерисовками. Очистки экрана выполняются периодически, помогают убрать следы и ореолы прошлых экранов.

Очищать каждые: полная перерисовка с миганием при чтении, убирает следы; 1 стр. — 30 стр. — раз в столько страниц, реже — быстрее, но больше следов; Никогда — только вручную

Очищать домашний экран: ВКЛ — каждый вход на домашний экран с полной перерисовкой (мигание), следов нет, от «Очищать каждые» не зависит; ВЫКЛ — быстрая перерисовка, следы возможны

Очищать после шторки: ВКЛ — при закрытии шторки над меню экран мигнёт чёрным и белым, следов шторки нет; над картинкой не мигает (картинка перерисовывается сама); ВЫКЛ (по умолчанию) — без очистки, следы возможны

Обновлять заставку: для своей картинки (Экран сна — Свой); через 1, 2 или 5 минут (по умолчанию 5) после засыпания читалка без подсветки один раз перерисовывает ту же заставку: на сером проступает след того, что было на экране перед сном (меню, полоса заголовка), за минуты он стекает, и после перерисовки картинка чистая; кнопка питания в это время будит как обычно; ВЫКЛ — заставка рисуется один раз

Обновлять картинки: картинка во вьювере через 1, 2 или 5 минут (по умолчанию 2) после открытия один раз перерисовывается с короткой очисткой (экран мигнёт чёрным и белым): уходит след меню и предыдущей картинки; ВЫКЛ — без перерисовки

Калибровка экрана: последний пункт «Экрана». Калибровочный экран картинок и калибровочный экран книг рисуют карточку из 33 серых ступеней и четырёх меток. Сфотографируйте её (можно несколько фото — так точнее) и рассчитайте поправку на странице KEINKT Calibrator (github.com/MikalaiKryvusha/KEINKT); файл panel_curve.txt (картинки и заставки) или panel_curve_book.txt (картинки в книгах) положите в скрытую папку /.crosspoint/ на карте (на Mac скрытые файлы показывает ⌘⇧.) и поставьте галочку — поправка читается с карты в этот момент; если галочка уже стояла, снимите и поставьте снова. Фото того же экрана с поправкой страница проверит и по нему уточнит поправку. Из обоих калибровочных экранов «Назад» сразу возвращает в меню калибровки; следующий «Назад» — в «Экран». Галочки «Калибровка картинок» (по умолчанию ВКЛ) и «Калибровка книг» (ВЫКЛ): снята — калибровочный экран показывает экран как есть (замер), стоит — с поправкой (проверка). Без файла картинки идут по встроенной кривой этой X4 Pro.

Настройки: Чтение

Настройки текста: экран с превью и вкладками Шрифт, Размер, Разметка, Стиль; смена переразмечает книгу

› Шрифт: Noto Sans (встроенный) или семейство из /.fonts

› Размер: кегль; Noto Sans — 12, 14, 16, 18 pt; TTF/OTF — 8–22 pt; CPFONT — установленные кегли

› Межстрочный интервал: 0% — строки по кеглю; +10% … +75% — добавка к высоте строки; +20% (Default) — исходное

› Межсловный интервал: ширина пробела 50–200% от обычной, шаг 25%

› Межбуквенный интервал: -2 … +2 px между буквами; 0 px — как в шрифте

› Доп. интервал абзаца: ВКЛ — пустая полоса между абзацами; ВЫКЛ — абзацы встык

› Отступ абзаца: красная строка; ВЫКЛ — без отступа; 1–5 — шириной в 1–5 пробелов

› Выравнивание: По ширине; По левому краю; По центру; По правому краю; Стиль книги — как задано в самой книге

› Поля: отступ текста от краёв экрана, 5–40 px, шаг 5

› Фокусное чтение: ВКЛ — начало каждого слова жирным (как Bionic Reading); ВЫКЛ — обычный текст

› Hyphenation (no preview): перенос слов; ВКЛ — переносит, строки ровнее; ВЫКЛ — слово целиком на новую строку

› Embedded Style (no preview): ВКЛ — оформление из CSS книги; ВЫКЛ — только настройки читалки

› Text Anti-Aliasing (no preview): ВКЛ — сглаженные серые края букв, листание чуть медленнее; ВЫКЛ — чисто чёрные буквы, быстрее

Управление шрифтами: скачать семейства шрифтов по Wi-Fi и управлять установленными

Ориентация чтения: Книжная; Альбомная — повёрнута по часовой; Книжная 180° — вверх ногами; Альбомная 180° — повёрнута против часовой

Изображения: картинки в EPUB; Показать — в оттенках серого, страница с картинкой — лишняя перерисовка; Заглушки — подпись вместо картинки; Скрыть — без картинок; Black & White — чёрно-белым узором, листается как текст; GIF — только первый кадр

Стиль меню чтения: Список — меню книги на весь экран; Панель — полосы сверху и снизу поверх страницы

Словарь: словарь StarDict для поиска слова; Нет — поиск выключен; строка есть, только если в /dictionaries лежит словарь

Настройка строки состояния: что в строке внизу при чтении; экран с превью

› Количество страниц главы: ВКЛ — страница и число страниц главы

› % прочтения книги: ВКЛ — процент прочитанного

› Полоса прогресса: Книга — прогресс книги; Глава — прогресс главы; Скрыть — без полосы

› Толщина индикатора прогресса: Тонкий; Средний; Толстый

› Заголовок: Книга — название книги; Глава — название главы; Скрыть — без заголовка

› Батарея: ВКЛ — значок батареи

› Строка состояния XTC: для книг XTC/XTCH; Скрыть; Низ; Верх

› Часы: время в строке; Скрыть; Вправо — справа; Влево — слева

Очистить кэш чтения: удаляет кэш книг в /.crosspoint; весь прогресс чтения теряется, книги заново размечаются при открытии

Настройки: Кнопки

Жесты кнопки «Домой»: что делает сенсорная Home; Нажатие — Домой; Двойное нажатие — Вкл./выкл. подсветку; Долгое нажатие — Меню

› Действия Home: Домой; Игнорировать; Перелистывание; Обновить экран; Ссылки и примечания; Подтвердить; CrossPoint Sync; Закладка; Словарь; Меню; Вкл./выкл. подсветку; Создать отрывок

Боковые кнопки: две кнопки листания, только в книге; Назад/Вперёд — левая назад, правая вперёд; Вперёд/Назад — наоборот; Выключено — не листают; Обе вперёд; Обе назад

Тачскрин для листания: ВКЛ — в книге тапы и свайпы листают, долгое касание выделяет, тап открывает ссылку; ВЫКЛ — листать только кнопками; то же, что Рука в шторке

Следующая страница: жест вперёд; Тап и свайп — оба; Только тап — тап по правым 2/3 экрана; Только свайп — свайп справа налево; Обратный тап — зоны тапа зеркально; Выключено — жестом не листает

Предыдущая страница: жест назад; Тап и свайп — оба; Только тап — тап по левой трети; Только свайп — свайп слева направо; Обратный тап — зоны тапа зеркально; Выключено — жестом не листает

Зоны тапа: тап включён в одну сторону — весь экран листает туда

Открывать меню: как открыть меню книги; ВЫКЛ — тапом не открывается, центр листает; Тап — тап в центре экрана; Свайп вверх — свайп от нижнего края

Боковая долго: удержание кнопки или тапа листания от 0,7 с; Ничего — обычное листание; Пропуск главы — EPUB: следующая или прошлая глава, TXT и XTC: ±10 страниц; Изменить ориентацию — поворот текста

Двойной клик питания: подсветка: ВКЛ — PWR 2 раза включает и выключает подсветку, одиночный клик «Подтвердить» срабатывает с паузой; ВЫКЛ — двойной клик подсветку не трогает

Питание коротко: Игнорировать — ничего, сон долгим нажатием; Сон — засыпает; Перелистывание — в книге следующая страница; Обновить экран — полная перерисовка, убрать следы; Ссылки и примечания — в книге выбор ссылки, после перехода PWR — назад; Подтвердить — как кнопка «Выбрать»

Быстрый возврат из ссылок: строка есть только при «Ссылки и примечания»; по замыслу ВКЛ — PWR после перехода по ссылке возвращает назад; в этой сборке возврат работает при любом значении

Настройки: Библиотека

Использовать метаданные книг: ВКЛ — в библиотеке название и автор из самой книги; ВЫКЛ — имя файла; действует при перестройке индекса

Скрывать прочитанные: ВКЛ — дочитанная до конца книга пропадает из недавних, листнул назад — вернётся; ВЫКЛ — остаётся

Прочитанные в Read: ВКЛ — дочитанная книга при закрытии переезжает в /read; ВЫКЛ — остаётся на месте

Настройки: Подключения

Wi-Fi сети: найти сеть и сохранить пароль; после выхода читалка тихо перезапускается обратно в Настройки

Bluetooth-пульт: Bluetooth вкл/выкл; Найти пульты — подключить пульт; Сопряжённые пульты — список, Забыть удаляет; Назначить кнопки — действие на кнопку пульта

CrossPoint Sync: общая позиция чтения с сервером CrossPoint или KOReader

› Имя пользователя, Пароль: учётная запись сервера

› URL сервера синхронизации: адрес сервера; пусто — по умолчанию

› Тип сервера: CrossPoint — сервер CrossPoint; KoSync — сервер KOReader; Другое — свой

› Свой заголовок 1, 2: доп. HTTP-заголовки к запросам, для своего сервера

› Сопоставление: как узнать ту же книгу на других устройствах; Имя файла — по имени; Бинарный — по содержимому файла

› Отправлять метаданные: ВКЛ — с позицией уходят имя файла, название и автор

› Режим синхронизации: Спрашивать — каждый раз выбор, взять позицию или отправить; Умная — простые случаи решает сама

› Синхронизировать отрывки: ВКЛ — отрывки тоже уходят на сервер

› Регистрация, Авторизация: создать учётную запись; проверить вход

Серверы OPDS: до 8 каталогов книг (имя, адрес, логин, пароль) для поиска и скачивания

Плагины: Включено — плагины с карты работают, на главном есть «Плагины»; Выключено — файлы остаются, не запускаются

Проверить обновление: сначала «Обновить прошивку?» — только разрешение проверить; после проверки видны текущая и новая версии, качает лишь по второму «Обновить»; по умолчанию везде «Отмена»; официальная прошивка заменит сборку krinik
